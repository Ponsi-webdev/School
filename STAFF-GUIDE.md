# Staff guide (demonstration)

Open the dashboard at `/admin/`. In the demo there are no passwords: choose a sample person. The real version uses an email and password.

**Write and publish news:** News > Write news. Fill in the title, summary and text. Save draft keeps it private. Preview shows how it will look. Publish makes it public. Unpublish takes it down. Delete asks you to confirm.
**Events:** Events > Add event. Times are East Africa Time. Only Published events appear on the website.
**Page content:** change the home banner, introduction and the headteacher's welcome.
**Admissions:** edit requirements, steps, dates and FAQs. Only put dates the school has confirmed. A document goes public only when you upload a PDF and tick Approved.
**Gallery:** add a photo, a caption and alternative text describing the picture. Only use photos you have permission to use.
**Enquiries (administrators and admissions staff):** open a message, then set New, In progress or Resolved. Do not reply from the dashboard; use the school's official contacts.
**Settings (administrators):** school name, contacts, social links, map location and colours. For the map, paste a Google Maps link, coordinates or a street address. The map appears only once a location is saved.
**Staff access (administrators):** add people and set roles. There must always be one administrator.
